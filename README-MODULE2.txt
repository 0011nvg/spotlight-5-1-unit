Spotlight 5 / Modules 1 + 2 / Victoria English Studio

Готовый сайт: index.html — модуль 1 и переход в новый модуль; module2.html — World Collector.

Для загрузки на GitHub Pages распакуйте ZIP и загрузите всё содержимое в корень репозитория. Сохраните папку assets. index.html должен быть прямо в корне. В Settings → Pages выберите main / root. Сборка и установка программ не требуются.

Для занятий используйте онлайн-ссылку сайта. Прогресс хранится только в браузере ученика на его устройстве. New student / Reset all — сброс перед следующим учеником.

Методика, ключи, примерная длительность и ограничения проверки — в TEACHER-GUIDE-MODULE2.md.
