SCHOOL MISSION — КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES

1. Распакуйте ZIP-архив.
2. Откройте нужный репозиторий на GitHub.
3. Загрузите В КОРЕНЬ репозитория всё содержимое архива:
   index.html, 404.html, favicon.svg, папку assets, .nojekyll,
   TEACHER-GUIDE.md и этот файл.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В Build and deployment выберите Deploy from a branch.
7. Выберите Branch: main и Folder: / (root), затем Save.
8. Подождите несколько минут и откройте появившуюся ссылку.

Важно: не помещайте файлы в дополнительную внешнюю папку. Папка assets
должна остаться рядом с index.html.

Прогресс хранится только в браузере на текущем устройстве. Перед занятием
с другим учеником используйте Teacher → Reset Student и подтвердите сброс.
